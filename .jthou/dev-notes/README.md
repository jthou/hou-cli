# Dev Notes 目录

本目录包含基于 Git 提交记录自动生成的开发笔记。

## 📝 文件说明

- `dev-notes-YYYY-MM-DD.md`: 按日期生成的开发笔记，包含该日期之前的提交记录总结

## 📋 内容结构

每份开发笔记包含以下内容：

1. **项目概览**: 项目的基本介绍
2. **最新开发进展**: 最近完成的任务和功能
3. **技术实现细节**: 关键技术实现的详细说明
4. **Bug 修复**: 修复的问题和解决方案
5. **文档更新**: 文档相关的更新
6. **测试统计**: 测试覆盖率和测试结果
7. **任务状态总结**: 已完成、进行中、待开始的任务
8. **代码重构**: 重构相关的信息
9. **UI/UX 改进**: 用户界面和体验的改进
10. **开发规范**: 代码规范和提交规范
11. **下一步计划**: 未来的开发计划

## 🔄 更新频率

开发笔记会根据 Git 提交记录定期更新，通常包含最近 20-30 次提交的总结。

## 📌 使用说明

- 查看最新的开发笔记了解项目进展
- 参考技术实现细节了解功能实现方式
- 查看任务状态了解项目整体进度
- 参考开发规范保持代码质量
