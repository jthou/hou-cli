# 写文章参考块（按会话）— 实现与设计对照

## 设计要点回顾

1. **存储**：`reference_blocks_${sessionId}`，每个会话独立
2. **跨页添加**：跳转 → 选择目标会话 → 添加
3. **模态**：会话列表（标题 + 更新时间）+ 新建会话
4. **边界**：
   - 无会话：直接新建并添加，不弹选择器
   - 仅一个会话：可默认选中 / 自动添加
   - 写文章页内添加：直接加到当前会话

## 差异说明

### 1. 无会话时自动新建（已修复）

当 `sessions.length === 0` 且 `!sessionsLoading` 时，自动调用 `handleAddToRefSelectSession(null, content)`，跳过模态。

### 2. 其他

- 内容预览、Toast 为实现阶段新增，与设计无冲突。
- 取消时直接丢弃内容，设计允许「可再定策略」。
