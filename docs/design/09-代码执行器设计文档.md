# 代码执行器设计文档

## 1. 项目概述

### 1.1 设计目标

代码执行器是 hou-cli 的核心基础设施之一，用于在安全的沙盒环境中执行用户代码和命令。

**核心需求**：
- 支持多种脚本语言（Python、Bash、Zsh、PowerShell、Batch）
- 提供安全隔离环境
- 资源限制（CPU、内存、时间）
- 跨平台支持（Windows、macOS、Linux）

### 1.2 设计原则

1. **安全性优先**：所有代码在隔离环境中执行
2. **资源可控**：限制 CPU、内存、执行时间
3. **跨平台兼容**：支持主流操作系统
4. **易于扩展**：支持添加新的语言和功能

## 2. 架构设计

### 2.1 整体架构

采用分层架构，从底层到上层：

```
┌─────────────────────────────────────────┐
│      CodeExecutorTool (AI 工具层)        │
│      提供给 AI 代理使用的接口            │
└─────────────────┬───────────────────────┘
                  │
┌─────────────────▼───────────────────────┐
│      SecureExecutor (安全层)             │
│      - 安全检查                          │
│      - 命令过滤                          │
│      - 路径验证                          │
└─────────────────┬───────────────────────┘
                  │
┌─────────────────▼───────────────────────┐
│   SubprocessExecutor (执行层)            │
│      - 进程管理                          │
│      - 资源限制                          │
│      - 跨平台支持                        │
└─────────────────┬───────────────────────┘
                  │
┌─────────────────▼───────────────────────┐
│     操作系统 (subprocess)                │
│      - Python 解释器                    │
│      - Shell 解释器                     │
└─────────────────────────────────────────┘
```

### 2.2 核心组件

#### 2.2.1 SubprocessExecutor（底层执行器）

**职责**：
- 创建和管理子进程
- 设置资源限制
- 处理进程输入/输出
- 超时控制

**关键特性**：
- 使用 `asyncio.create_subprocess_exec` 创建进程
- 支持资源限制（Linux/macOS 使用 `resource` 模块）
- 临时工作目录隔离
- 自动清理临时文件

**支持的语言**：
```python
LANGUAGE_MAPPING = {
    "python": {
        "executors": {
            "linux": ["python3", "python"],
            "darwin": ["python3", "python"],
            "windows": ["python", "py"]
        },
        "execute_method": "code"  # 使用 -c 参数
    },
    "bash": {...},
    "zsh": {...},
    "powershell": {...},
    "batch": {...}
}
```

#### 2.2.2 SecureExecutor（安全包装器）

**职责**：
- 验证执行请求
- 过滤危险命令
- 检查受限路径
- 审计日志记录

**安全检查**：
1. **语言白名单**：只允许预定义的语言
2. **命令黑名单**：禁止危险命令（`rm`, `sudo`, `format` 等）
3. **路径限制**：禁止访问系统敏感目录
4. **代码长度限制**：最大 10KB

**黑名单命令**：
```python
COMMAND_BLACKLIST = [
    "rm", "del", "format", "sudo", "su",
    "chmod", "chown", "chgrp",
    "mkfs", "fdisk", "dd",
    "killall", "pkill"
]
```

#### 2.2.3 CodeExecutorTool（AI 工具接口）

**职责**：
- 提供给 AI 代理使用的工具接口
- 参数验证和转换
- 结果格式化

**工具参数**：
- `code`: 要执行的代码
- `language`: 代码语言
- `timeout`: 超时时间（默认 30 秒，最大 300 秒）
- `explanation`: 代码说明（可选）

#### 2.2.4 AutoCodeExecutor（自动执行器）

**职责**：
- 从 LLM 输出中自动提取代码块
- 自动执行检测到的代码
- 将执行结果合并到输出中

**代码提取**：
- 支持 Markdown 代码块格式：`` ```python ... ``` ``
- 支持多种语言标记：`python`, `bash`, `shell`, `powershell` 等
- 自动去重

## 3. 数据模型

### 3.1 ExecutionRequest（执行请求）

```python
@dataclass
class ExecutionRequest:
    code: str                    # 代码内容
    language: str                # 语言类型
    timeout: int = 30            # 超时时间（秒）
    memory_limit_mb: Optional[int] = None    # 内存限制（MB）
    cpu_limit: Optional[float] = None         # CPU 限制
    working_dir: Optional[str] = None         # 工作目录
    explanation: Optional[str] = None         # 说明
```

### 3.2 ExecutionResult（执行结果）

```python
@dataclass
class ExecutionResult:
    success: bool                # 是否成功
    output: str = ""             # 标准输出
    error: str = ""              # 错误输出
    exit_code: int = 0           # 退出码
    resource_usage: Optional[ResourceUsage] = None  # 资源使用
    language: str = ""            # 语言
    code: str = ""               # 代码
    timestamp: Optional[datetime] = None      # 时间戳
```

### 3.3 ResourceUsage（资源使用）

```python
@dataclass
class ResourceUsage:
    memory_used_mb: float = 0.0           # 内存使用（MB）
    cpu_used_percent: float = 0.0         # CPU 使用率（%）
    execution_time_seconds: float = 0.0    # 执行时间（秒）
```

## 4. 安全机制

### 4.1 进程隔离

- **临时工作目录**：每个执行任务使用独立的临时目录
- **进程隔离**：使用子进程执行，不影响主进程
- **自动清理**：执行完成后自动清理临时文件

### 4.2 资源限制

#### Linux/macOS
- **内存限制**：使用 `resource.RLIMIT_AS`
- **CPU 时间限制**：使用 `resource.RLIMIT_CPU`
- **文件描述符限制**：使用 `resource.RLIMIT_NOFILE`

#### Windows
- **超时机制**：使用 `asyncio.wait_for` 控制执行时间
- **进程监控**：使用 `psutil` 监控资源使用

### 4.3 命令过滤

- **黑名单检查**：禁止执行危险命令
- **路径验证**：禁止访问系统敏感目录
- **代码长度限制**：防止过大的代码块

### 4.4 审计日志

- 记录所有执行请求
- 记录执行结果（成功/失败）
- 记录资源使用情况

## 5. 跨平台支持

### 5.1 平台检测

```python
def _detect_platform(self) -> str:
    system = platform.system().lower()
    if system == "darwin":
        return "darwin"
    elif system == "windows":
        return "windows"
    else:
        return "linux"
```

### 5.2 语言支持矩阵

| 语言 | Linux | macOS | Windows |
|------|-------|-------|--------|
| Python | ✅ | ✅ | ✅ |
| Bash | ✅ | ✅ | ❌ |
| Zsh | ✅ | ✅ | ❌ |
| PowerShell | ✅ (pwsh) | ✅ (pwsh) | ✅ |
| Batch | ❌ | ❌ | ✅ |

### 5.3 执行方法

- **code 模式**：使用 `-c` 参数直接执行代码（Python、Bash、Zsh）
- **command 模式**：使用 `-Command` 参数（PowerShell）
- **file 模式**：写入临时文件后执行（Batch，暂未实现）

## 6. 使用示例

### 6.1 基本使用

**通过 CodeExecutorTool**：
```python
tool = CodeExecutorTool()
result = tool.execute(
    code="print('Hello, World!')",
    language="python"
)
```

### 6.2 自动执行

**通过 AutoCodeExecutor**：
```python
executor = AutoCodeExecutor()
result = await executor.process_llm_output(
    llm_output="""
    这是一个 Python 代码示例：
    ```python
    print('Hello, World!')
    ```
    """,
    auto_execute=True
)
```

### 6.3 安全执行

**通过 SecureExecutor**：
```python
executor = SecureExecutor()
request = ExecutionRequest(
    code="print('Hello')",
    language="python",
    timeout=30
)
result = await executor.execute_code_safely(request)
```

## 7. 错误处理

### 7.1 常见错误

1. **语言不支持**：返回明确的错误信息
2. **平台不支持**：说明当前平台不支持该语言
3. **执行超时**：终止进程并返回超时错误
4. **资源不足**：记录资源使用情况
5. **安全检查失败**：返回安全检查错误

### 7.2 错误恢复

- 自动清理临时文件
- 确保进程正确终止
- 记录详细的错误信息

## 8. 性能优化

### 8.1 资源监控

- 使用 `psutil` 监控资源使用
- 实时获取内存和 CPU 使用情况
- 记录执行时间

### 8.2 输出处理

- 限制输出大小（10MB）
- 异步处理输出流
