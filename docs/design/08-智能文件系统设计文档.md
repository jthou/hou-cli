# 智能文件系统设计文档

## 1. 项目概述

### 1.1 项目背景

参考 ArkFS（An LLM embedded file system）项目，考虑为 hou-cli 添加文件操作能力。

### 1.2 设计结论

**最终结论**：**不需要实现任何新功能**

### 1.3 原因分析

1. **已有 CodeExecutorTool**
   - 可以执行 Python 代码（`os`, `shutil`, `pathlib`）
   - 可以执行 Shell 命令（`rm`, `cp`, `mv`, `mkdir` 等）
   - 已有安全沙盒环境
   - 已有资源限制和错误处理

2. **AI 可以生成代码**
   - AI（特别是 coder 模型）可以理解用户意图
   - AI 可以生成合适的文件操作代码/命令
   - AI 可以组合多个操作完成复杂任务

3. **无需额外实现**
   - 不需要新的工具类
   - 不需要新的服务层
   - 不需要额外的依赖
   - 不需要额外的安全机制

### 1.4 使用方式

**文件操作完全通过 CodeExecutorTool 实现**：

1. **用户请求**："删除 test.txt"
2. **AI 生成代码**：
   - Python: `os.remove('test.txt')`
   - Shell: `rm test.txt`
3. **执行**：通过 `CodeExecutorTool` 执行（底层使用 subprocess）
4. **返回结果**：执行结果反馈给用户

**示例**：
- 用户："把所有的 .tmp 文件移动到 backup 文件夹"
- AI 执行：
  1. 调用 `FileSearchTool` 搜索 `*.tmp`
  2. 生成代码：
     ```python
     import shutil
     from pathlib import Path
     Path('backup').mkdir(parents=True, exist_ok=True)
     for file in ['file1.tmp', 'file2.tmp', ...]:
         shutil.move(file, 'backup/')
     ```
  3. 通过 `CodeExecutorTool` 执行

## 2. 核心功能

### 2.1 文件操作实现方式

**通过 `CodeExecutorTool` 执行代码/命令实现文件操作**

#### 2.1.1 创建文件/目录

**用户请求**："创建一个 backup 文件夹"

**AI 生成代码**：
```python
# Python
from pathlib import Path
Path('backup').mkdir(parents=True, exist_ok=True)
```

或
```bash
# Shell
mkdir -p backup
```

#### 2.1.2 删除文件/目录

**用户请求**："删除 test.txt"

**AI 生成代码**：
```python
# Python
import os
os.remove('test.txt')
```

或
```bash
# Shell
rm test.txt
```

**如果需要回收站删除**：
```python
# Python (需要 send2trash)
import send2trash
send2trash.send2trash('test.txt')
```

#### 2.1.3 复制文件/目录

**用户请求**："把 test.txt 复制到 backup 文件夹"

**AI 生成代码**：
```python
# Python
import shutil
shutil.copy('test.txt', 'backup/')
```

或
```bash
# Shell
cp test.txt backup/
```

#### 2.1.4 移动/重命名文件/目录

**用户请求**："把 test.txt 重命名为 old_test.txt"

**AI 生成代码**：
```python
# Python
import shutil
shutil.move('test.txt', 'old_test.txt')
```

或
```bash
# Shell
mv test.txt old_test.txt
```

#### 2.1.5 获取文件信息

**用户请求**："查看 test.txt 的信息"

**AI 生成代码**：
```python
# Python
from pathlib import Path
import os
from datetime import datetime

path = Path('test.txt')
info = {
    'size': path.stat().st_size,
    'modified': datetime.fromtimestamp(path.stat().st_mtime),
    'exists': path.exists(),
    'is_file': path.is_file(),
    'is_dir': path.is_dir()
}
print(info)
```

### 2.2 与现有工具配合

#### 2.2.1 文件搜索 + 文件操作

**场景**：用户说"删除所有 .tmp 文件"

**AI 执行流程**：
1. 调用 `FileSearchTool` 搜索 `*.tmp` 文件
2. 获取搜索结果列表：`['file1.tmp', 'file2.tmp', ...]`
3. 生成删除代码：
   ```python
   import os
   for file in ['file1.tmp', 'file2.tmp', ...]:
       os.remove(file)
   ```
4. 通过 `CodeExecutorTool` 执行

#### 2.2.2 复杂操作组合

**场景**：用户说"把所有的 .tmp 文件移动到 backup 文件夹"

**AI 执行流程**：
1. 调用 `FileSearchTool` 搜索 `*.tmp` 文件
2. 生成组合代码：
   ```python
   import os
   import shutil
   from pathlib import Path
   
   # 创建 backup 文件夹
   Path('backup').mkdir(parents=True, exist_ok=True)
   
   # 移动文件
   tmp_files = ['file1.tmp', 'file2.tmp', ...]
   for file in tmp_files:
       shutil.move(file, 'backup/')
   ```
3. 通过 `CodeExecutorTool` 执行

### 2.3 使用示例

**用户输入**："创建一个 config.json 文件，内容为 {'key': 'value'}"

**AI 执行**：
```python
# 通过 CodeExecutorTool 执行
import json
from pathlib import Path

config = {'key': 'value'}
Path('config.json').write_text(json.dumps(config, indent=2))
```

## 3. 架构设计

### 3.1 整体架构

**极简设计**：不需要新工具，直接使用现有工具

```
┌─────────────────────────────────────────┐
│         AI Agent (Orchestrator)          │
│  ┌──────────────┐  ┌──────────────────┐ │
│  │FileSearchTool│  │ CodeExecutorTool  │ │
│  └──────────────┘  └──────────────────┘ │
│  ┌──────────────┐                       │
│  │  GvimTool    │                       │
│  └──────────────┘                       │
└─────────────────┬───────────────────────┘
                  │
                  │ AI 生成代码/命令
                  ↓
┌─────────────────▼───────────────────────┐
│      SecureExecutor (沙盒执行)           │
│  - Python (os, shutil, pathlib)         │
│  - Shell (rm, cp, mv, mkdir, etc.)      │
└─────────────────────────────────────────┘
```

### 3.2 核心组件

#### 3.2.1 CodeExecutorTool（已存在）

**职责**：
- 执行 Python 代码
- 执行 Shell 命令
- 安全沙盒环境

**文件操作支持**：
- Python: `os`, `shutil`, `pathlib` 等标准库
- Shell: `rm`, `cp`, `mv`, `mkdir`, `rmdir` 等命令

#### 3.2.2 AI 模型（特别是 coder 模型）

**职责**：
- 理解用户意图
- 生成合适的文件操作代码/命令
- 处理错误和异常情况

### 3.3 数据流

#### 3.3.1 简单操作流程

```
用户输入："删除 test.txt"
  ↓
AI 理解意图（使用 coder 模型）
  ↓
生成代码：os.remove('test.txt')
  ↓
调用 CodeExecutorTool.execute()
  ↓
SecureExecutor 执行
  ↓
返回结果
```

#### 3.3.2 复合操作流程

```
用户输入："把所有的 .tmp 文件移动到 backup 文件夹"
  ↓
AI 规划步骤：
  1. 调用 FileSearchTool 搜索 *.tmp
  2. 生成组合代码（创建目录 + 移动文件）
  ↓
执行步骤 1 → 获取文件列表
  ↓
执行步骤 2 → 通过 CodeExecutorTool 执行代码
  ↓
返回结果
```

### 3.4 与现有系统集成

#### 3.4.1 工具使用

**不需要注册新工具**，直接使用现有的：
- `CodeExecutorTool`: 执行文件操作代码
- `FileSearchTool`: 搜索文件
- `GvimTool`: 编辑文件

#### 3.4.2 模型选择

**建议**：对于文件操作任务，使用 `deepseek-coder` 模型
- 更擅长生成代码
- 更了解文件系统操作
- 更少出错

## 4. 技术选型

### 4.1 代码执行

**选择**：使用现有的 `CodeExecutorTool` 和 `SecureExecutor`

**支持的语言**：
- **Python**：使用 `os`, `shutil`, `pathlib` 等标准库
- **Shell**：使用 `rm`, `cp`, `mv`, `mkdir` 等命令

**已有保障**：
- `SecureExecutor` 提供沙盒环境
- 资源限制（CPU、内存、时间）
- 路径验证和权限检查

### 4.3 错误处理

**由 AI 处理**：
- AI 生成代码时可以包含错误处理
- 执行结果反馈给 AI，AI 可以重试或调整

### 4.4 依赖总结

**无需新增依赖**：
- ✅ 使用现有的 `CodeExecutorTool`
- ✅ 使用 Python 标准库（`os`, `shutil`, `pathlib`）
- ✅ 使用 Shell 命令（系统自带）

**可选依赖**（如果需要回收站删除）：
- `send2trash`: 仅在 AI 生成的代码中使用，不是工具依赖
