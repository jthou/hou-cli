# 代码执行交互机制设计

## 1. 现状分析

### 1.1 当前实现

**安全限制**：
- `SecureExecutor` 有命令黑名单，包括 `sudo`、`su` 等
- 检测到危险命令直接拒绝执行
- 没有用户确认机制

**自动执行**：
- `AutoCodeExecutor` 有 `require_confirmation` 参数，但实现为空
- 代码直接执行，没有用户交互

**交互输入**：
- 没有处理交互式输入（如密码、确认等）
- 子进程无法与用户交互

### 1.2 存在的问题

1. **无法执行需要权限的命令**
   - `sudo` 命令被黑名单阻止
   - 无法输入密码
   - 无法执行需要管理员权限的操作

2. **没有用户确认机制**
   - 危险操作直接执行
   - 用户无法审查代码
   - 无法取消执行

3. **无法处理交互式输入**
   - 代码需要用户输入时无法处理
   - 密码输入无法实现
   - 确认提示无法响应

## 2. 设计目标

### 2.1 核心需求

1. **用户确认机制**
   - 危险操作需要用户确认
   - 显示代码内容，让用户审查
   - 支持批准/拒绝/修改

2. **权限提升支持**
   - 支持 `sudo` 命令（需要用户确认和密码）
   - 支持其他需要权限的操作
   - 安全地处理密码输入

3. **交互式输入支持**
   - 处理代码中的 `input()` 等交互
   - 支持密码输入（隐藏显示）
   - 支持多轮交互

4. **安全机制**
   - 密码不存储、不记录
   - 确认操作有审计日志
   - 危险操作有明确警告

### 3.5 交互式输入处理

#### 3.5.1 检测交互式输入

```python
def detect_interactive_input(code: str) -> bool:
    """检测代码是否需要交互式输入"""
    
    # Python
    if "input(" in code:
        return True
    
    # Shell
    if "read " in code:
        return True
    
    # 其他交互式命令
    interactive_commands = ["sudo", "passwd", "ssh"]
    for cmd in interactive_commands:
        if cmd in code:
            return True
    
    return False
```

#### 3.5.2 处理交互式输入

```python
async def execute_interactive(
    code: str,
    language: str
) -> ExecutionResult:
    """执行需要交互式输入的代码"""
    
    # 使用 pexpect 或 pty 处理交互
    import pexpect
    
    child = pexpect.spawn(
        f"{language} -c '{code}'",
        encoding='utf-8'
    )
    
    # 监听输出，检测需要输入的地方
    while True:
        try:
            index = child.expect([
                pexpect.EOF,
                'password:',
                'Password:',
                '输入:',
                '>>>',
                pexpect.TIMEOUT
            ], timeout=1)
            
            if index == 0:  # EOF
                break
            elif index in [1, 2]:  # 密码输入
                password = await get_password_input()
                child.sendline(password)
            elif index == 3:  # 普通输入
                user_input = await get_user_input()
                child.sendline(user_input)
            elif index == 4:  # Python prompt
                # 处理 Python 交互式会话
                pass
            else:  # TIMEOUT
                # 显示当前输出
                output = child.before
                console.print(output)
                continue
                
        except pexpect.EOF:
            break
    
    # 获取最终输出
    output = child.before
    exit_code = child.exitstatus
    
    return ExecutionResult(
        success=exit_code == 0,
        output=output,
        exit_code=exit_code
    )
```

### 3.6 前端交互实现

#### 3.6.1 确认对话框

```python
# frontend/ui/interactive_executor.py
from rich.prompt import Confirm, Prompt
from rich.panel import Panel
from rich.console import Console

class InteractiveExecutor:
    """交互式执行器（前端）"""
    
    def __init__(self, console: Console):
        self.console = console
    
    async def request_confirmation(
        self,
        code: str,
        risk_level: RiskLevel,
        reason: str
    ) -> ConfirmationResult:
        """请求用户确认"""
        
        # 显示代码和警告
        self.console.print(Panel(
            f"[bold yellow]⚠️  危险操作确认[/bold yellow]\n\n"
            f"检测到危险操作：{reason}\n"
            f"风险级别：{risk_level.value}\n\n"
            f"[bold]代码内容：[/bold]\n"
            f"[code]{code}[/code]\n\n"
            f"[bold yellow]警告：[/bold yellow]{self._get_warning(risk_level)}",
            title="确认执行",
            border_style="yellow"
        ))
        
        # 获取用户选择
        if risk_level == RiskLevel.HIGH:
            # 高风险需要明确确认
            approved = Confirm.ask(
                "是否执行此操作？(需要输入密码)",
                default=False,
                console=self.console
            )
            
            if approved:
                password = Prompt.ask(
                    "Password",
                    password=True,
                    console=self.console
                )
                return ConfirmationResult(
                    approved=True,
                    password=password
                )
            else:
                return ConfirmationResult(approved=False)
        else:
            # 中低风险简单确认
            approved = Confirm.ask(
                "是否执行此操作？",
                default=False,
                console=self.console
            )
            return ConfirmationResult(approved=approved)
    
    def _get_warning(self, risk_level: RiskLevel) -> str:
        """获取警告信息"""
        warnings = {
            RiskLevel.HIGH: "此操作需要管理员权限，可能影响系统安全",
            RiskLevel.MEDIUM: "此操作可能修改或删除文件",
            RiskLevel.LOW: "此操作相对安全，但仍需确认"
        }
        return warnings.get(risk_level, "")
```
