## 遇到的问题和解决方案

### 问题1: 推理模型的 `reasoning_content` 字段

**问题**: 推理模型在工具调用时需要在消息中包含 `reasoning_content` 字段，否则会返回400错误。

**解决方案**: 
- 在 `_execute_single_turn()` 中提取 `reasoning_content`
- 在构建消息历史时，如果有工具调用，添加 `reasoning_content` 字段

**代码位置**: `backend/core/agent/planning/autonomous_executor.py`

### 问题2: B站视频下载的412错误

**问题**: 使用 yt-dlp 下载B站视频时遇到 HTTP 412 错误（Precondition Failed）。

**解决方案**: 
- 推理模型自主尝试了多种方法：
  - 尝试不同的工具（yt-dlp, you-get）
  - 尝试不同的参数（quality, cookies_from_browser）
  - 最终使用 you-get 成功下载

**说明**: 这展示了自主执行器的自适应能力，能够根据错误信息调整策略。

### 问题3: 规划文件未创建

- 或者文件已创建但路径不同
