### 2. 模型选择测试失败（4个）

**问题**：推理任务被误判为代码任务

**失败案例**：
- "分析这个项目的代码结构并生成报告" → 选择了 `deepseek-coder` 而不是 `deepseek-reasoner`
- "搜索相关信息，然后生成一篇文章" → 选择了 `deepseek-chat` 而不是 `deepseek-reasoner`

**原因分析**：
1. **关键词匹配顺序问题**：
   - 代码关键词检查在推理关键词检查之前
   - "代码结构"中的"代码"被匹配到代码关键词
   - 导致推理任务被误判为代码任务

2. **关键词优先级问题**：
   - 推理关键词（如"分析"、"报告"）应该优先于代码关键词
   - 需要改进匹配逻辑，考虑上下文

**修复方案**：
- ✅ 已调整关键词匹配顺序：推理关键词检查优先
- ✅ 分离代码操作关键词和代码生成关键词
- ✅ 添加更多推理关键词（"报告"、"研究"、"调研"等）

**修复后的逻辑**：
```python
# 优先判断：如果任务包含推理关键词，使用推理模型
if any(keyword in task_lower for keyword in reasoning_keywords):
    return reasoning_model

# 然后判断代码操作关键词
if any(keyword in task_lower for keyword in code_keywords):
    return code_model

# 最后判断代码生成关键词
if any(keyword in task_lower for keyword in code_generation_keywords):
    return code_model
```

1. **推理任务优先**：

   - 代码操作（执行、运行）→ 代码模型
