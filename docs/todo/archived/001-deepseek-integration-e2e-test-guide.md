## 一、测试前准备

### 1.1 环境配置

1. **确保已安装依赖**
   ```bash
   pip install -r requirements.txt
   ```

2. **配置 API Key**
   ```bash
   # 复制示例文件
   cp env.example .env
   
   # 编辑 .env 文件，设置真实的 API Key
   DEEPSEEK_API_KEY=your_real_api_key_here
   ```

3. **验证配置**
   ```bash
   # 检查环境变量是否正确加载
   python -c "from dotenv import load_dotenv; import os; load_dotenv(); print('API Key:', '已设置' if os.getenv('DEEPSEEK_API_KEY') else '未设置')"
   ```

### 1.2 启动服务

**终端 1 - 启动后端**:
```bash
python -m backend.main
```

**终端 2 - 启动前端**:
```bash
python -m frontend.main chat
```

**或者使用统一启动**:
```bash
make start
```

### 2.1 基本功能测试（P0）

## 四、常见问题

### Q1: 后端启动失败，提示 "DEEPSEEK_API_KEY 环境变量未设置"
**A**: 检查 `.env` 文件是否存在，API Key 是否正确配置。

### Q2: 前端无法连接到后端
**A**: 
1. 确认后端已启动
2. 检查端口是否被占用
3. 查看后端日志是否有错误

### Q3: 流式输出有重复字符
**A**: 这是已知问题，已在 TODO-003 中修复。如果仍有问题，请检查 `frontend/ui/stream_handler.py`。

### Q4: 多轮对话上下文不工作
**A**: 
1. 检查会话 ID 是否正确传递
2. 查看后端日志，确认 `ContextManager` 是否正常工作
3. 检查 `Orchestrator` 是否正确使用上下文
