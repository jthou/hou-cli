# 推理模型工具执行问题分析

## 问题描述

用户发现推理模型（Claude）在接收到任务时，只是提供了操作指导（如如何使用 you-get 下载视频），而没有自动执行工具调用来完成实际任务。

## 问题分析

### 1. 系统提示不够明确

**当前系统提示**（`orchestrator.py` 第 1067-1155 行）：
- 只提到了浏览器工具、Google搜索工具、天气工具的使用规则
- 没有明确要求推理模型**必须使用工具执行任务**，而不是只提供指导
- 缺少对视频下载工具、代码执行工具等工具的明确说明

**问题**：
- 推理模型可能理解为"提供指导"而不是"执行操作"
- 系统提示没有强调"必须使用工具执行，不要只提供文字指导"

### 2. 工具调用机制依赖 LLM 主动调用

**当前机制**：
- 系统通过 Function Calling 机制提供工具
- LLM 需要主动决定是否调用工具
- 如果 LLM 认为"提供指导"就足够了，就不会调用工具

**问题**：
- 推理模型可能认为提供操作步骤就完成了任务
- 没有强制要求执行工具的逻辑

### 3. 模型选择逻辑可能影响工具调用

**当前逻辑**：
- 推理模型用于"复杂推理、策略制定、工具选择决策"
- 但推理模型可能更倾向于"分析"而不是"执行"

**问题**：
- 推理模型可能被用于任务分析，但实际执行时可能没有切换到执行模式

## 解决方案

### 方案 1: 增强系统提示（推荐）

在系统提示中明确要求推理模型必须使用工具执行任务：

```python
system_prompt = """你是一个智能助手，能够帮助用户解决各种问题。

【重要】执行原则：
1. **必须使用工具执行任务**：当用户要求执行操作（如下载、搜索、执行命令等）时，必须使用相应的工具来执行，不要只提供文字指导
2. **不要只提供指导**：如果任务可以通过工具完成，必须调用工具执行，而不是告诉用户如何操作
3. **工具调用优先级**：优先使用工具执行，只有在工具不可用时才提供替代方案

【工具使用规则】：

1. **视频下载工具（video_downloader）**：
   - 当用户要求下载视频时，必须使用 video_downloader 工具
   - 例如："下载这个视频" → 必须调用 video_downloader 工具
   - 例如："用 you-get 下载视频" → 必须调用 video_downloader 工具（工具会自动选择 you-get）
   - 不要只告诉用户如何使用 you-get，必须直接执行下载

2. **代码执行工具（execute_code）**：
   - 当用户要求执行命令或代码时，必须使用 execute_code 工具
   - 例如："执行 ls /home" → 必须调用 execute_code 工具
   - 不要只提供命令，必须直接执行

3. **浏览器工具（browser）**：
   - 当用户要求"打开"、"访问"、"查看"网站时，必须使用 browser 工具
   - 例如："打开 www.google.com" → 必须调用 browser 工具

4. **Google 搜索工具（google_search）**：
   - 当用户要求"搜索"、"查找"网络信息时，必须使用 google_search 工具
   - 例如："搜索 Python 教程" → 必须调用 google_search 工具

5. **天气工具（get_weather）**：
   - 当用户询问天气信息时，必须使用 get_weather 工具
   - 不要编造天气信息，必须调用工具获取

【执行流程】：
1. 分析用户需求
2. 识别需要执行的操作
3. **直接调用相应的工具执行**（不要只提供指导）
4. 基于工具执行结果给出回复

【禁止行为】：
- ❌ 不要只提供操作步骤或指导
- ❌ 不要告诉用户"你可以使用 xxx 工具"
- ❌ 不要只列出命令而不执行
- ✅ 必须直接调用工具执行任务
- ✅ 基于工具执行结果给出回复
"""
```

### 方案 2: 添加工具调用强制检查

在工具调用循环中，如果 LLM 返回的是指导性文本而不是工具调用，可以：

1. **检测指导性回复**：识别包含"你可以"、"使用"、"执行"等指导性词汇的回复
2. **强制工具调用**：如果检测到指导性回复，但任务明显需要工具执行，可以：
   - 重新提示 LLM："用户要求执行操作，请直接调用工具，不要只提供指导"
   - 或者自动识别任务类型并直接调用相应工具

### 方案 3: 改进模型选择逻辑

**问题**：推理模型可能更适合"分析"而不是"执行"

**解决方案**：
- 任务分析阶段：使用推理模型分析任务
- 工具执行阶段：切换到对话模型或代码模型（根据工具类型）
- 或者：推理模型用于"工具选择决策"，但执行时明确要求调用工具

1. ✅ 更新系统提示，明确要求必须使用工具执行
2. ⚠️ 添加工具调用检测和强制机制（可选）
