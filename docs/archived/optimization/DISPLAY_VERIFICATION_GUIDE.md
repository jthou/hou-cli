# 前后端交互显示效果验证指南

## 验证目标

验证前后端交互的显示效果是否符合设计：

1. ✅ **状态行同一行更新**：状态信息在同一行实时更新，不产生重复行
2. ✅ **心跳机制**：每30秒左右发送一次状态更新，保持连接活跃
3. ✅ **进度输出**：清晰显示任务执行进度和状态
4. ✅ **自动换行**：有实际内容输出时，自动结束状态行并换行

### 方法2: 手动验证（交互式）

**使用前端交互式界面**：

```bash
# 启动后端（终端1）
export BACKEND_PORT=6080
export ENABLE_AUTONOMOUS_EXECUTION=true
export STREAM_TIMEOUT=600
python -m backend.main

# 运行前端（终端2）
export BACKEND_PORT=6080
python -m frontend.main chat "下载视频 https://www.bilibili.com/video/BV1jMqgBEERW?t=0.5 ，并从音频中提取字幕"
```

**观察要点**：

1. **状态行更新**：
   - 应该看到状态行在同一行更新
   - 格式：`处理中 | 任务正在执行中... | ⏱️ 30秒`
   - 不应该产生多行重复的状态信息

2. **心跳机制**：
   - 每30秒左右应该看到状态更新
   - 即使没有实际进度，也应该有状态更新

3. **内容输出**：
   - 当有实际内容（如工具调用、结果）时，状态行应该自动结束
   - 内容应该正常显示在新行

## 故障排查

### 问题1: 状态行不更新

**症状**：看不到状态行更新

**检查**：
1. 后端是否发送状态更新（查看后端日志）
2. 前端是否正确解析状态消息
3. Live组件是否正常工作

**解决**：
- 检查后端日志：`tail -f ~/Library/Application\ Support/hou-cli/logs/backend.log`
- 运行自动化测试：`python scripts/test_display_verification.py`

### 问题2: 状态行换行

**症状**：每次状态更新都产生新行

**原因**：前端没有使用Live组件或状态行处理逻辑有问题

**解决**：
- 检查 `frontend/ui/stream_handler.py` 中的状态行处理逻辑
- 确保使用 `live.update()` 而不是 `console.print()`

### 问题3: 心跳不工作

**症状**：长时间任务没有状态更新

**检查**：
1. 后端心跳机制是否启用
2. 心跳间隔配置是否正确（30秒）
3. 前端超时设置是否足够长

**解决**：
- 检查后端代码：`backend/api/routes.py` 中的心跳逻辑
- 检查环境变量：`STREAM_TIMEOUT` 是否设置足够大
