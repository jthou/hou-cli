# 对齐 .env 和 env.example 文件

## 方法 1：手动对齐（推荐）

### 步骤：

1. **备份 .env 文件**
   ```bash
   cp .env .env.backup
   ```

2. **打开 .env 文件，找到模型配置部分**

3. **将 env.example 中的模型配置部分复制到 .env**

   需要更新的部分：
   - `# OpenAI 服务模型名称` 及其下面的注释和可选值列表
   - `# Anthropic 服务模型名称` 及其下面的注释和可选值列表
   - `# Google 服务模型名称` 及其下面的注释和可选值列表
   - `# xAI 服务模型名称` 及其下面的注释和可选值列表
   - `# Perplexity 服务模型名称` 及其下面的注释和可选值列表

4. **保留 .env 中已设置的实际值**

   例如，如果 `.env` 中有：
   ```
   OPENAI_MODEL=gpt-5
   ```
   
   更新后应该保持这个值，但注释部分要使用 `env.example` 中的最新版本。

## 方法 2：使用脚本自动对齐

运行同步脚本：
```bash
python scripts/sync_env_models.py
```

脚本会：
- 自动备份 `.env` 文件
- 从 `env.example` 复制最新的模型配置说明
- 保留 `.env` 中已设置的实际配置值

## 需要对齐的配置项

### OpenAI 模型配置（第 228-239 行）
- 更新模型列表，添加 O1 系列和 O3 快照版本

### Anthropic 模型配置（第 254-262 行）
- 更新模型列表，添加 4.5 系列模型

### Google 模型配置（第 279-287 行）
- 更新模型列表，添加多模态图像模型

### xAI 模型配置（第 302-307 行）
- 保持现有配置（已是最新）

### Perplexity 模型配置（第 322-328 行）
- 保持现有配置（已是最新）

## 注意事项

1. **不要覆盖敏感信息**：API Key 等敏感信息应该保留在 `.env` 中
2. **检查配置值**：确保更新后的配置值仍然有效
3. **测试配置**：更新后建议测试一下配置是否正常工作
