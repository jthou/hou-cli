#### 任务开始时
- ✅ 自动检测复杂任务
- ✅ 自动创建规划文件（task_plan.md, findings.md, progress.md）
- ✅ 将规划内容注入到 system_prompt

#### 工具调用前
- ✅ 读取规划文件
- ✅ 将规划内容注入到 LLM 上下文

#### 工具调用后
- ✅ 自动更新进度记录

- ✅ 错误自动记录到 task_plan.md

#### 对话完成后
- ✅ 自动评估对话质量
- ✅ 评估结果记录到 findings.md
- ✅ 低分对话记录到错误表

### 3. 配置项支持

环境变量配置：
- `ENABLE_PLANNING`: 启用/禁用规划功能（默认：true）
- `PLANNING_WORK_DIR`: 规划文件工作目录（默认：项目根目录/plans）
- `PLANNING_MIN_TASK_LENGTH`: 最小任务长度（默认：20）
- `PLANNING_COMPLEXITY_THRESHOLD`: 复杂度阈值（默认：0.3）

### 4. 错误处理

## 使用示例

### 1. 环境配置

在 `.env` 文件中添加：

```bash
ENABLE_PLANNING=true
PLANNING_WORK_DIR=./plans
PLANNING_MIN_TASK_LENGTH=20
PLANNING_COMPLEXITY_THRESHOLD=0.3
```

### 2. 自动触发

当用户提交复杂任务时，系统会自动：
1. 检测任务复杂度
2. 创建规划文件
3. 在工具调用前后自动更新
4. 对话完成后评估并记录

### 3. 规划文件位置

规划文件保存在 `项目根目录/plans/` 目录下：
- `{session_id}_task_plan.md`
- `{session_id}_findings.md`
- `{session_id}_progress.md`
